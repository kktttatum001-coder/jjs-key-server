คู่มือและหลักการจัดตกแต่งภายใน (Interior Design Knowledge)

รวมหลักวิชาการและเทคนิคการตกแต่งบ้านสำหรับประยุกต์ใช้งานจริง

ทฤษฎีสี 60-30-10 & แสง

  • 60% สีหลัก: ผนัง เพดาน พื้น (สร้างบรรยากาศรวม)
  • 30% สีรอง: โซฟา ผ้าม่าน ตู้ขนาดใหญ่ (สร้างความสมดุล)
  • 10% สีไฮไลต์: หมอนอิง ภาพติดผนัง แจกัน (สร้างจุดเด่น)
  • อุณหภูมิแสง: Warm White (2700K) เหมาะกับห้องนอน, Cool/Daylight (4000K-6500K) เหมาะกับมุมทำงาน

ระยะห่างสเปซมาตรฐาน

  • ทางเดินหลัก (Main Walkway): กว้างอย่างน้อย 80-90 ซม.
  • โซฟาถึงโต๊ะกลาง: เว้นระยะ 35-45 ซม. ให้เดินลุกสบาย
  • ระยะดูทีวี: ขนาดทีวี (นิ้ว) x 1.2 = ระยะนั่งห่าง (นิ้ว)
  • รอบเตียงนอน: ควรมีพื้นที่ว่างด้านข้างอย่างน้อย 50-60 ซม. สำหรับขึ้น-ลงและปูเตียง

คู่มือเลือกวัสดุตกแต่ง

  • พื้น SPC: กันน้ำ 100% ทนปลวก เหมาะกับคอนโดและบ้าน
  • พื้นไม้ลามิเนต: ให้สัมผัสอบอุ่น ไม่ทนน้ำขัง
  • โซฟาผ้า: ระบายอากาศดี นุ่มสบาย แต่เปื้อนง่าย
  • โซฟาหนัง: เช็ดทำความสะอาดง่าย ดูหรูหรา และมีอายุการใช้งานยาวนาน

Independent Study (IS) รายงานโครงงานการศึกษาค้นคว้าด้วยตนเอง

โครงงาน: เว็บไซต์แนะแนวและจำลองการจัดแต่งห้องด้วยระบบ 2D และ 3D Interactive

โครงงานนี้จัดทำขึ้นเพื่อแก้ปัญหาผู้ใช้งานที่ไม่สามารถนึกภาพสเปซการจัดวางเฟอร์นิเจอร์ในชีวิตจริงได้ โดยรวมเอาองค์ความรู้การตกแต่งภายใน สถาปัตยกรรมเว็บไซต์ และระบบประมวลผลกราฟิก 2D/3D เข้าด้วยกัน

วัตถุประสงค์โครงงาน

  • เพื่อศึกษาและรวบรวมหลักการแต่งบ้านสไตล์ต่างๆ
  • เพื่อพัฒนาระบบจำลองแปลน 2D และ 3D บนเว็บ
  • เพื่อประเมินความพึงพอใจของกลุ่มตัวอย่างผู้ใช้งาน

เทคโนโลยีที่ใช้ (Tech Stack)

  • Frontend UI: HTML5, Tailwind CSS, Javascript (ES6)
  • 2D Graphics: HTML5 Canvas API
  • 3D Rendering: Three.js (WebGL Engine)

ประโยชน์ที่คาดว่าจะได้รับ

  • ช่วยลดความผิดพลาดในการเลือกซื้อเฟอร์นิเจอร์
  • ช่วยวางแผนงบประมาณตกแต่งล่วงหน้าได้
  • เป็นสื่อการเรียนรู้ด้าน Interior Design เบื้องต้น
